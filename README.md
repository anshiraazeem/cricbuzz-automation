# Cricbuzz Automation Project

## Overview

This project focuses on automating key functionalities of the Cricbuzz application using test automation tools.

## Features Automated

* Match search functionality
* Live score validation
* Navigation between different sections
* UI element verification

## Tech Stack

* Java
* Selenium / Appium
* TestNG
* Maven

## Project Structure

* `src/test/java` → Test cases
* `pages` → Page Object Model classes
* `BaseTest` → Common setup and configuration

## How to Run

1. Clone the repository
2. Open in Eclipse / IntelliJ
3. Run test classes using TestNG
